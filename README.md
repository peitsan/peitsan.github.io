# Peican Lin - Academic Homepage

> Personal academic homepage of Peican Lin (林培灿), Ph.D. Candidate at MILab, SCUT.

🔗 **Live Site**: https://peitsan.github.io


## 🚀 Quick Start

```bash
# Clone the repo
git clone https://github.com/peitsan/peitsan.github.io.git
cd peitsan.github.io

# Install dependencies
npm install

# Preview locally
npm run dev

# Build for production
npm run build
```

## 📁 Project Structure

```
src/
├── App.vue                      # Main layout
├── components/
│   └── sections/
│       ├── Title.vue             # Profile header
│       ├── Publications.vue      # Papers list
│       ├── Research.vue           # Research topics
│       └── Contact.vue            # Contact info

```
